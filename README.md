# Palm_Detection-
A real-time Palm Detection project built using Python, OpenCV, and MediaPipe. The system identifies and tracks the palm and hand landmarks from live video input, providing fast and accurate hand detection for interactive applications

Features :-
Real-time palm detection using a webcam.
Accurate hand and palm landmark tracking.
Lightweight and fast processing.
Supports gesture-based applications.
Easy to integrate into other computer vision projects.

Technologies Used :-
Python
OpenCV
MediaPipe
NumPy
